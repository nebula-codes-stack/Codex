Release notes

What's new

  • Auth: Login at /login with a hashed password stored in .nova/auth.json.
  • Correct directory: Terminal sessions now default to the server project directory, not ~.
  • Settings: Simple UI toggles and runtime configuration at /settings.
  • Debugging: Server diagnostics are available at /debug.
  • Sessions: Create, attach, rename, close, and replay stored output from detachable PTY sessions.
  • Power tools: Use the command palette, copy output, download logs, and clear stored history from the toolbar.
  • User commands: Add custom quick commands in /settings.
